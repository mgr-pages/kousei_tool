# 印刷のページ全体を読める大きさにする（2026年11月26日）

「印刷・PDFで保存」に付けたページ全体（[2026-11-26_印刷にページ全体を付ける.md](2026-11-26_印刷にページ全体を付ける.md)）が小さく、紙では字が読めない、という指摘への対応の記録です。

## 1. 原因

| 原因 | 中身 |
|---|---|
| 載せる大きさ | 原稿と成果物を左右に並べ、2つで用紙の幅（190mm）に収めていた。原寸に対して A4 縦は 44%、A4 横は 31%、A3 見開きは 22%、縦に長いページ（720×2600pt）は 37% |
| 画像の細かさ | 表示用の画像を「長い辺 2400 画素まで」で縮めていたため、縦に長いページは幅が粗い（原寸で 66dpi 相当） |
| 画像の濃さ | 表示用の画像は薄めてある（元の55%＋白45%）ものを、そのまま印刷していた |

## 2. 変えたこと

| 場所 | 前 | 後 |
|---|---|---|
| 並べ方 | 原稿と成果物を1枚に並べる | 1面ずつ別の紙 |
| 大きさ | 用紙の幅に2面を収める | 原寸の7割以上。1枚に収まらないページは 8mm ずつ重ねて分ける（「（1/2・左）」「（2/3）」のように示す）。見出しの横に原寸に対する％ |
| 紙の向き | A4 縦だけ | A4 の縦・横のうち、枚数の少ないほう（同じなら大きく載るほう） |
| 表示用の画像 | 長い辺 2400 画素まで | 面積 2400×2400 画素まで（長い辺は 6000 画素まで）。A4 は前と同じ（縮めない） |
| 濃さ | 薄めた画像のまま | 元の濃さに戻して描く |
| 枠の線・番号 | 画像の幅に合わせた大きさ（見開きでは番号が字を隠すほど大きい） | 紙の上で同じ大きさ（線 0.4mm・番号の字 2.3mm）。番号どうしが重なるときは右へずらす |

照合の中身は変えていません。

## 3. 確かめたこと（印刷の見え方で PDF に書き出して測る。数値は PDF の中の画像の大きさから）

| ページ（模擬データ・架空） | 前：原寸に対する大きさ | 後：大きさ・分け方 | 後：紙の上の細かさ | 印刷の枚数（全体）前→後 |
|---|---|---|---|---|
| A4 縦（注釈PDF・4ページ・印刷する項目 26） | 44% | 81%・1枚（縦） | 248ppi | 14→18 |
| A4 横（A3 見開きと同じ PDF の1ページ目） | 31% | 76%・1枚（横） | 262ppi | 30→34（2ページ分） |
| A3 見開き（同じ PDF の2ページ目） | 22% | 81%・左右2枚（縦） | 214ppi | （上の行に含む） |
| 縦に長いページ（720×2600pt） | 37% | 71%・3枚（縦） | 178ppi | 24→28 |

| 確かめたこと | 結果 |
|---|---|
| 紙の上の字（A4 縦・81%。200dpi で描いて見る） | 本文の字・枠・番号が読める。番号の重なり（前は1つ隠れていた）がなくなった |
| 見出しと画像が同じ紙に収まるか | すべての紙で収まる（A4 横の紙は横向きの紙として出る） |
| 照合の結果（直す前の版と比べる：注釈PDF・紙のスキャン1通り・レイアウトが違う原稿・架空の A4 横＋見開き） | 4通りとも全項目が同じ |
| 結果を保存→開き直して印刷 | 開き直す前と、ページ全体の紙の画素がすべて同じ |
| 保存するファイルの大きさ | A4 は変わらない。縦に長いページ 0.55MB→1.18MB、A4 横＋見開き 1.30MB→1.48MB |

## 4. 未解決と次

- 未解決なし（ページ全体の紙は増える：1面ずつ・7割以上で載せるため。枚数を少なくしたいときは「印刷・PDFで保存（一覧だけ）」を使う）
