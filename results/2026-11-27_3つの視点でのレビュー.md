# 3つの視点でのレビュー（2026年11月27日）

プランナー・デザイナー・初めて使う人の3つの視点でツールを見て、指摘を評価し、直す点と方針を決めて反映した記録です。

## 1. 進め方

- 画面を実際に動かして、11の場面を撮って見た。
  - 最初の画面、ファイルを入れたあと、照合中、結果、項目を選んだところ、パタパタ、詳細設定、保存・印刷のメニュー、旧版だけの結果、読めないファイルを入れたとき、狭い画面。
  - 使ったのはテスト用の架空データ。旧版だけの照合は実データでも見た。
- 見る範囲は、作業の流れに沿った6つの場面に分けた：入口、照合中、結果の把握、項目の確認、出力、画面の幅と見た目。
- 画像で分からない所（説明の出し方・画面の幅ごとの並び方など）は、画面の作りを読んで確かめた。

## 3. 評価と方針

- 決め方は3つ：見逃し・手間・迷いにつながるか（影響）、直す作業の量、これまでの方針（画面の説明を減らしてシンプルにする）に合うか。
- 直すもの：影響が高・中で、作業が軽く、方針に合うもの。
- 直さないもの：
  - 進み具合の言葉：進んでいることが分かれば足りる。
  - 「新しい校正」が2か所：入口の近くと、結果の近くの両方で使う。
  - 項目の説明：画面の説明を減らす方針を守る。

## 4. 反映したこと

| 指摘 | 直し方 |
|---|---|
| 比べていない所の知らせ | その知らせがあるときは「お知らせ」を開き、「お知らせ N件（比べていない所があります）」と橙色で示す。その知らせも橙色にする |
| 結果に気づきにくい | 照合が終わったら、結果の位置まで画面を動かす |
| 狭い画面でページの表示が見えない | 一覧とページの表示を左右に並べる幅を、1000px から 880px まで広げた。それより狭いときは、ページの表示を一覧の上に固定する（高さは画面の半分ほど） |
| 何を入れるかが分からない・拡張子の並び | 欄ごとに1行の説明を出し、拡張子の並びはやめた（説明にマウスを置くと、入れられる形式が出る）。原稿「赤字・指示を入れたもの（PDF・画像・Excel・Word など）」、成果物「今回チェックするPDF」、旧版「前回の成果物のPDF（前回から変わった所も見ます）」 |
| 読めないファイルに緑のチェック | 読めないファイルがある欄は、赤い枠と赤の「！」にする |
| 英語の混ざる知らせ | 「PDFとして開けません。壊れているか、PDFではないファイルです。」（パスワード付きは「パスワード付きのPDFは使えません。パスワードを外したPDFを入れてください。」） |

## 5. 確かめたこと（直したあとの画面を撮って見た）

| 確かめたこと | 結果 |
|---|---|
| 最初の画面 | 3つの欄に1行の説明が出る。拡張子の並びがなくなり、欄の見た目がそろった |
| 読めないファイル | 赤い枠と「！」が付き、知らせは日本語だけ |
| 照合が終わったとき（幅 1440px） | 結果の位置まで動く。比べていない所の知らせがあるときは、お知らせが開いて橙色で出る |
| 幅 1000px | 一覧とページの表示が左右に並ぶ（前は、ページの表示が一覧のいちばん下だった） |
| 幅 800px | ページの表示が上に残り、その下で一覧を動かせる。項目を選ぶと、ページの表示に枠が出る |
| 照合の結果 | 画面の表示だけを変えたので、照合の項目は変わらない |
| 途中の不具合 | 知らせに付けた印の名前が、画面のほかの所の名前とぶつかり、知らせが1字ずつ縦に並んだ。名前を変えて直した。狭い画面で、ページの表示の高さの指定がほかの指定に負けていたのも直した |
