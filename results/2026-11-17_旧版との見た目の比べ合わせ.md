# 旧版との見た目の比べ合わせ（2026年11月17日）

未解決の1つ目「旧版＋成果物の経路は、写真・図版の変化を項目として出していない」への対応の記録です。利用者のファイルはリポジトリに入れていません（数だけを書きます）。

## 1. 問題と方針

旧版＋成果物の経路は文字データだけを比べていたため、写真の差し替え・図やグラフの変更・ロゴの移動などは一覧に出ませんでした（パタパタで目で見れば気づけるが、見逃しの元になる）。

| 案 | 内容 | 判断 |
|---|---|---|
| A. 部品で比べる | PDFの画像・図形の部品を旧版と成果物で突き合わせる | 書き出し直すと画像の分け方・図形の分け方が変わるため、同じ見た目でも部品は合わない。採らない |
| B. 描画で比べる | 旧版の描画を成果物に重ね、違う画素のうち、文字の変化・字の移動で説明できないものを出す | 注釈PDFの経路と同じ考え方（全数の消し込み）。採る |

## 2. 作る途中で分かったことと対応

| 分かったこと | 対応 |
|---|---|
| ページの対応づけの変換が、文章の送りで動いた字に引っぱられる（テストキットの旧版で「横に3%縮む」「本文の分だけ35pt上へ」。配置は同じ）。図・枠のふちがみな違いになった（30件） | 同じ字と対応づいた組から位置合わせを求め直す（動いていない組が5%以上あれば位置そのまま、なければいちばん多い動き）。パタパタの重ね方・消えた字の印の位置にも使う |
| 消えた字の説明の枠を、緩い変換で写していた | 求め直した位置合わせで写す |
| 成果物の書き込み（ピンクの帯）が、「成果物の書き込み」の項目と二重に出た | 書き込みの字からつながるピンクの画素を除く |
| 同じ字・同じ位置で、字の太さだけが変わった所（誤りを入れる道具の副作用）が、1字ずつ別の項目・「文字以外」として出た | 「字の見た目が変わった」（色・太さ・書体）として分け、同じ行の字は1件にまとめて字を示す |
| 実際の改訂版どうしで、写真の細かい網目（描き直しの模様）・画像のつなぎ目の細い線など、見た目では同じ所が大量に出た（カタログ20ページで208件） | 2画素（約0.25mm）以内のずれは違いにしない。粗く見て同じ所（4×4画素の平均どうしの差が40を超えるます目が3つ未満）と、太さ3画素以下の線だけの違いは出さない。目安は、下の実データで、本当の変化と揺れを分けられる値を測って決めた |
| ページのふちの細い枠線（片方の版だけにある）が、枠の範囲にほかの違いを吸い込み、ページ全体で1件になった | 細い線だけの大きなまとまりには、ほかをまとめない |

## 4. 未解決と次
