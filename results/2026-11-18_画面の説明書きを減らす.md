# 画面の説明書きを減らす（2026年11月18日）

「説明書きが多すぎて画面がごちゃごちゃしている。もっとシンプル・ミニマムに」という依頼への対応の記録です。照合の中身（項目・判定）は変えていません。

## 1. 変えたこと

| 場所 | 前 | 後 |
|---|---|---|
| 上の帯 | ツールの説明の一文、「ファイルはこのブラウザの中だけで処理し、外部には送信しません」 | 説明の一文を消し、「外部送信なし」（元の文は、ポインタを置いたときに出す）。「保存した結果を開く」をここへ移す |
| ファイルを入れる所 | 見出し「チェックするファイルを入れてください」と、その下の説明、各欄の説明の一文、「形式」の字、読めない形式の注意書き、「またはここへドラッグ」 | 欄の名前（原稿・成果物・旧版）と任意・必須、形式の札（拡張子）、「ファイルを選ぶ」だけ。各欄の説明とドラッグでも入れられることは、欄の名前にポインタを置いたときに出す。読めない形式は、入れたときにその場で知らせる（これまでどおり） |
| 照合ボタン・進み具合 | 「原稿と照合・前回と比べる」、「原稿 4ページ・成果物 4ページ・旧版 4ページで照合します（対応するページは自動で探します）（目安：1分以内）」 | 「照合」（原稿なしは「チェック」「前回と比べる」）、「目安：1分以内」（ページ数は各欄に出ている） |
| 詳細設定 | 「詳細設定（チェックする項目）」と、その下の説明の一文 | 「詳細設定」だけ（説明はポインタを置いたときに出す） |
| 結果の上 | お知らせを1行ずつ、ページの対応の一行、かかった秒数、「見出しや種類を押すと、それだけを表示します（…）」、「ほかに、指示どおりと自動で確認できたもの N件（一覧には出していません。…）」 | お知らせは「お知らせ N件」に畳む（押すと開く。ページの対応もこの中。項目が1件もないときと印刷では開く）。秒数と押し方の説明は消す。「ほか、自動で確認済み N件」 |
| 道具の帯 | 「次の未確認へ」「確認済み（OK）を隠す」「新しい校正を始める」、保存の選択肢ごとの説明 | 「次の未確認」「OKを隠す」「新しい校正」、保存の選択肢は名前だけ（説明はポインタを置いたときに出す） |
| 一覧の項目 | 札の横の説明の一文、「p.1（原稿 1ページ目 → 成果物 1ページ目）」、パタパタの説明、選んだ項目のキー操作の案内 | 説明の一文は、成果物だけのチェック・表の照合（その文が中身）のほかは、札にポインタを置いたときと印刷・CSVにだけ出す。ページは「p.1」。パタパタはボタンだけ。キー操作はメモの欄にポインタを置いたときに出す |
| ページの表示 | 「1 2 3 4 ページ」、「p.1（原稿 1ページ目 → 成果物 1ページ目）」の一行、「選んだ項目（一覧のオレンジの枠の項目）」 | 「ページ」の字と一行を消し、どのページかは画像の上の見出し（「原稿 1ページ目」「成果物 1ページ目」）に添える。枠の色の説明は「選択中」 |

## 2. 確かめたこと

| 確かめたこと | 結果 |
|---|---|
| 架空データ25通りの照合の項目（これまでの出力と比べる） | 25通りとも同じ |
| 結果を保存して開き直したとき（項目・一覧の文・お知らせ） | 同じ |
| 印刷の見え方 | 項目の説明の一文とお知らせが出る |
| 画面を動かしたときの誤り（コンソールのエラー） | なし（照合・項目の選択・詳細設定・保存のメニュー・成果物だけのチェック） |
