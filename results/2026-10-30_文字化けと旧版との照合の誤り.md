# 自動テストの記録：文字化け・旧版との照合の誤り・詳細設定（2026年10月30日）

模擬データ（文言はすべて架空）での結果と、利用者の実データでの件数だけを残しています。

## 利用者の報告

利用者の実データ（カタログ20ページ。旧版あり・原稿なし）で、文字が化けて読めない所（記号やアラビア文字のような字の並び）と、誤った照合が多く出た。

## 原因と直したこと

| 原因 | 直したこと |
|---|---|
| フォントに「文字番号 → 文字」の対応表（ToUnicode）がなく、文字番号の並びが Adobe-Identity の CID フォント（PDFium などで書き出した Noto Sans CJK JP）。pdf.js は文字番号をそのまま文字として返し、アラビア文字・ヘブライ文字の番号に当たると、字の並びまで入れ替わっていた（PyMuPDF で読んでも同じく化ける） | Noto Sans CJK JP 2.004 から作った「文字番号 → 文字」の表（63,137字。縦書き用・異体字の字形は元の字に戻す）を、pdf.js の文字の読み取りに差し込んだ（`src/data/make_noto_cid2u.py`・`build.js`）。実データの2つのPDFで使われている文字番号は、すべて表にあった |
| 旧版との照合で、字の番号が続いているだけの、ページの左右の端どうしの字をつないだ（左右のページ番号「11」「12」の「11」を、「11」の2字目と「12」の1字目に当てる） | 照合で、成果物の文字のまとまりの境目をまたぐたびに、ごく小さな手間をかける（手間が同じ並べ方のうち、またがない方を選ぶ）（`PC.collate`） |
| 旧版にない字の続きの区切りがずれた（「[品番]」のあとに「[品番2]」を足した所を、「][品番2」を足した、と出す） | 旧版にない字の続きを、前後の同じ字の上で滑らせ、かっこ・空白・字の種類・離れた所の切れ目にそろえる（`slideNew`）。照合の中でも、足した字・消した字の続きを同じように寄せる（`PC.shiftEdits`） |
| かっこの閉じ忘れの誤検出：縦書きの「（」と「ページ）」の間に横組みの数字のまとまりがある、段組みの注記で前の段の終わりの「【」と次の段の始めの「】」が逆の順に読まれる、注記の番号「（※」と「1）」が別のまとまり（図の中の回転した注記） | 前のまとまりの開きかっこのすぐ近く（向きは問わない）の閉じかっこは、番号の閉じかっこでなく対とする。まとまりの終わりの閉じていないかっこと、別のまとまりの始めの開いていないかっこ（間の字が合わせて40字まで・近い所）は対とする |
| 回転した文字（図の縦向きの注記）の枠を、横向きの文字として求めていた（ページの外にはみ出した枠になり「ページの端で文字が切れています」と出た。描画を確かめると、文字はページの中に収まっていた） | 字の並ぶ向きと上の向きに沿って、字の枠の四隅を求める |
| 表記ゆれの指摘の位置が2字ずれた | kuromoji の語の位置（word_position）は、「℃、」のように2字以上の語で区切った文のあとでずれる。語の字数を足して位置を求める（語をつなげると元の文字列に戻ることを、実データの5,566のまとまりで確かめた） |
| 「一点一点」を「同じ語の重なり」とした | くり返して使う言い方（「一」＋1字、「ひとつ」「ひとり」）と、3字までの音の言葉（小さい字・長音を含むカタカナ）は除く |
| 「時間がかかる」と「本件に係る」を表記ゆれとし、候補に「係り」を出した | 文化審議会国語分科会「「異字同訓」の漢字の使い分け例（報告）」（平成26年）の133項目の読みは、かなの書き方がどの漢字の語に当たるか決められないため、漢字の書き方と組にするときは候補を出さず、「意味によって漢字を使い分ける語です。同じ語か確かめてください」と添える |

あわせて、点検の中で見つけた次の誤検出も直した。

- 「受付は5時までです」の「でで」を助詞の重なりとした（`までです`）。「木でできた」「高いものの」も同じ。辞書があれば語に分けて、同じ助詞が続くものだけを出す
