# 差し込み印刷（名刺など）の照合（2026年11月10日）

利用者から「名刺の成果物（PDF・8ページ）を、データの Excel と照合したが正しく校正されなかった。特殊な例だが、状況に応じて校正のやり方を変えるなどして対応できるようにしたい。既存の校正物はそのままに」との依頼を受け、原因を分析し、差し込み印刷を自動で見分けて行ごとに照合する仕組みを加えた記録です。

利用者のファイル（Excel・PDF）はリポジトリに入れていません。ここには件数だけを書きます（会社名・氏名・連絡先などは書かない）。模擬データの会社・人・番号はすべて架空です。

## 1. 分析：なぜ正しく校正できなかったか

| 項目 | 内容 |
|---|---|
| 成果物 | Illustrator で作った名刺。1人分が表（日本語）と裏（英語）の2ページで、4人分の8ページ。仕上がり（TrimBox）55×91mm。上にページの外までかかるページ情報 |
| 原稿 | Excel。シートが2つ（名刺にした4人の表と、同じ人を含む約50人の表。役職が違う）。見出しは1行目。表の上に会社名・住所の行、見出しのない列に事業所の電話・FAXの表、セルの中の改行（役職は2〜3行、携帯は国内の書き方と国番号つきの書き方の2行）、人数の行 |
| 今までの照合 | データファイルの原稿は、表の全体を成果物のページと文章として突き合わせていた。表の1行だけが載る名刺のページでは、ほかの人の行がすべて「成果物にない」と出る。2つ目のシートの同じ人の行も当たる。縦組みの氏名（1字ずつの行）・字間をあけた大文字のローマ字・国番号つきの電話番号は、字の並びとしては合わない |
| 結果 | 37件。ほとんどが意味のない項目で、照合になっていなかった |

正しく照合するには、次が要ると考えました。

1. 差し込み印刷であることを見分ける（表の1行が成果物の1ページ（表・裏）に載る）
2. 成果物のページごとに、表のどの行かを決める（似た行・別のシートの同じ人と取り違えない）
3. その行の値をページの中で探す（全角・半角、大文字・小文字、空白、電話番号の書き方、ローマ字の姓と名の順番、縦組みを吸収する）
4. どのページにも載る値（会社名・住所・事業所の電話番号）を、表の上の行・見出しのない列から読み、どのページにもあるかを見る
5. 表にない字（英語の住所・「T」「E」などの書き込み）は、照合する原稿がないため、同じ作りのほかのページと比べる

## 2. 搭載したもの（`src/js/merge.js`）

| 段階 | 内容 |
|---|---|
| 見分ける | 見出しの行の下の、見出しのある列に3つ以上字がある行を1件とする。ページごとに値が最も多く見つかる行を求め、同じ表のほかの行がほとんど見つからないページが2ページ以上・文字のあるページの6割以上なら、差し込み印刷とみなす。そうでなければ、今までの比べ方のまま（カタログの表などは当たらない） |
| 行ごとの照合 | 値が見つからなければ、ほかの行で同じ列の値があった位置の字を並べて「（列）が違う」と出す。表と裏の両方に載るはずの値は、ページごとに確かめる。載らない列（勤務地・内線など）は見ない |
| 値に続く字 | 値のすぐ前後に続く字（同じ語・同じ行で空白1つほどの次の語・縦組みの同じ列のすぐ下の字）を同じ列のほかの値と比べ、増えた字を出す |
| 共通の値 | 会社名・住所・事業所の電話番号の小さな違い、見当たらないもの、行ごと消えたもの |
| 同じ作りのページ | 表にない字を行の位置ごとに比べ、少しだけ違う所・行の大半が消えた所・増えた字・消えた行を「ほかのページと違う？」（確認だけ）として出す |
| 画面 | 原稿の表示は、その行の「項目｜原稿の値」の表。すべて一致したページは「自動で確認済み」。詳細設定に「差し込み印刷（名刺など）の行ごとの照合」を加えた（36項目。説明書きの項目数が古いままだったのも直した） |

差し込み印刷と見分けたときだけ、その表のシートの照合をこれに置き換えます。ほかの原稿・成果物の比べ方は変えていません。

## 5. この取り組みの限界（自己分析）

- 実データで確かめたのは、利用者の名刺1件（4人分・8ページ）だけです。ほかは自分で作った模擬データ（名刺・社員証の2つの作り）で、実際の差し込み印刷の多様さ（宛名ラベル・はがき・社員証・案内状など）では確かめていません。
- 1ページに1件のもの（表と裏など何ページかに分かれてもよい）だけに対応します。1ページに3件以上を並べたもの（ラベルの面付けなど）は差し込み印刷として見分けず、今までの比べ方になります。1ページに2件のものは1件だけを照合し、その旨を知らせます。
- 値は字の並びで探します。表と成果物で書き方を変えたもの（番地の「1-2-3」を縦組みで「一丁目二番三号」にしたもの、郵便番号を枠に「-」なしで入れたもの、和暦と西暦など）は、違いとして出ます。
- 同じ作りのページが2ページしかないと、ほかのページとの比べ合わせ（増えた字・決まった字の違い・消えた行）はできません。1ページにしかない行の位置（1人だけ3行の役職の3行目など）の、空白をはさまずに増えた語でない増え方も、比べる相手がなく見つけられないことがあります。
- 表にない決まった字（英語の住所など）は、ほかのページの多くと比べるだけです。1人だけの事業所の名刺の英語の住所は確かめられません。まるごと違う決まった文は、事業所ごとの書き分けとみなして出しません。
- 見つからない値の「成果物の値」は、ほかのページで同じ列の値があった位置の字から推し量ったものです。位置が分からないときは、同じ列のほかの値の所を、おおよその場所として示します。
