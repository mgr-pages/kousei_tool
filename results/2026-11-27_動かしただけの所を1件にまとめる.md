# 動かしただけの所を1件にまとめる（2026年11月27日）

初校（旧版）と再校（成果物）を照合すると、同じ中身を動かしただけの所で項目が大量に出て、件数がふくらむ、という指摘への対応の記録です。

依頼の要点：確かめたいのは、動いた所がどの範囲か、動いた中身が前回と同じか、だけ。

## 1. 現状の分析（実データ：初校と再校、見開き2面。数はツールの出力と、試作の測定から）

| 面 | 項目（全体） | 文字の項目 | 文字以外の見た目の項目 | 見た目の違いのまとまり | そのうち、ずらすと旧版と同じになるもの |
|---|---|---|---|---|---|
| 表 | 28件 | 10件 | 9件 | 101 | 91（面積で 80%） |
| 裏 | 118件 | 65件 | 51件 | 116 | 80 |

- **表**：見た目の違いの大部分は、旧版の別のページ（別案）の中身を、そのまま横へ移したものでした。いまのツールは当たったページとだけ比べていて、別のページは「成果物のどのページにも当たらない」として比べていませんでした。
- **裏**：見た目の違いの大部分は、段ごとの上下のずれと、いくつかの札・帯の移動でした。
  - 文字の項目65件は、段落の書き直しによる本当の変化で、移動によるものではありません。

## 2. 課題

| 課題 | 中身 |
|---|---|
| 位置の基準がページに1つ | 旧版をページ全体の1つの位置合わせで重ねて比べるため、ページの中で動かしたブロック・写真・アイコンは、元の所と移った先の両方が違いになる |
| 移動元を探す範囲が狭い | 同じページの同じ位置としか比べない。旧版の別のページ（別案）から移した中身を見つけられない（そのページは、成果物の同じ範囲に当たる別のページがあると、比べる相手から外れる） |
| 出す単位が合わない | 違いのまとまりごとに1件を出すため、1つの移動が何件にも分かれる。「動いた」「中身は同じ」とは示さないので、1件ずつ目で確かめるしかない |

## 3. 手段の候補

| 候補 | よい点 | 弱い点 |
|---|---|---|
| A. 違いのまとまりごとに、旧版の中を探して、ずらすと同じになるかを画素で確かめる（両方の向き） | 写真・図形・アウトライン化した字・文字のどれでも使える。「中身が同じか」をそのまま確かめられる。旧版の別のページも探せる | 探すのに時間がかかる（大きいまとまりだけを低い解像度で探して抑える）。小さい同じ形（チェックの印など）は、別の所に当たることがある（近い所を優先し、小さすぎる動きは移動としない） |
| B. PDFの部品（文字・画像・図形）どうしを突き合わせる | 部品が同じかを正確に確かめられる | 書き出し直したPDFでは部品の分け方・画像の圧縮・アウトライン化が変わり、当たらないことが多い。作るのが重い |
| C. 文字の動きだけから移動を求める | 速い・正確 | 写真・図形・アウトライン化した字の移動、別のページからの移動は分からない |
| D. ページの対応を範囲ごとにする（1つの成果物のページに、旧版の複数のページを当てる） | 別案のページを移した場合は解ける | ページの中の移動は解けない |

## 4. 選んだ手段

A を中心にし、C の字の動きを動き方の候補に使う（速く、正確に当たるため）。D の場合（別のページから移したもの）も、A で旧版のほかのページを探して扱う。

## 5. 載せた機能（`analyze.js` の `explainMoves`。詳しくは README の「移動の見分け」）

- 見た目の違いのまとまりごとに、両方の向きで確かめる。
  - 成果物の側：その所の中身が、旧版のどこから移ってきたか。
  - 旧版の側：その所にあった旧版の中身が、成果物のどこへ移ったか。
- たまたま重なっただけの動きは除く。縦・横に少し（6画素）ずらすと違いがはっきり増える所（ぴったり重なる所）だけを、動きのよりどころにする。
  - まっすぐな縁やなめらかなグラデーションは、ずらしても重なるので、よりどころにならない。
- どちらの側も移動で説明できた所を「移動した所」とし、同じ動きのものは1件にまとめる。
  - 範囲は、同じ動きで動いた字まで広げる。
  - 動き・移動元（ほかのページなら何ページ目から）と、中身が同じかを示す。
  - 旧版の切り抜き・パタパタ表示は、動かした元の所を重ねる。
- 移動した範囲の中で、動かして重ねても違う所は「移動した中の違い」として別に出す（見逃さないように）。
- 移ってきた中身の下で、旧版の中身がなくなった所は「置き換わった所」として1件にまとめる。
- 結果の概要に「移動した所（範囲と中身を確認）」の区分を足した（確認だけ）。

## 6. 確かめたこと

| 確かめたこと | 結果 |
|---|---|
| 実データの項目 | 全体 146件 → 120件。文字以外の見た目の項目 60件 → 34件（表 9 → 7、裏 51 → 27） |
| 表（別案のページを移したもの） | 1件の「旧版の別のページから移ってきた所」になった（その中の違い3件は、移したあとに直した本当の違い）。当たったページの中身が置き換わったことは1件で出る。お知らせも「中身が成果物のページに移っていました」に変わった |
| 裏（段ごとのずれ・札の移動） | 動きごとに1件（6件）になった（「下へ ○mm移動（中身に違い ○か所）」の形） |
| テストキットの旧版と成果物（`test/look`。図版の差し替え・グラフの棒の高さ・ロゴの位置・アイコン） | 4か所とも見つけた（余分 0件）。ロゴは「上へ 6.3mm移動（中身は同じ）」になった。途中の版では、高さを変えた棒がほかの棒から「移動（中身は同じ）」とされていた（変化を見逃す誤り）。たまたま重なっただけの動きを除く条件を足して直した |
| 自動テスト一式（直す前の版と比べる） | 採点はすべて同じ。違いは、旧版との見た目の試験でロゴが「移動した所」になったこと（見つけた数・余分な検出は同じ）と、移動の試験を足したことだけ |
| 架空データの試験（`test/move`：同じページの中で動かしたブロック・字の一部を消して動かしたブロック・旧版の別のページから移したブロック） | 7項目すべて OK（移動した所 3件・中身が同じか・置き換わった所 1件・消えた字は文字の項目に出る・動かしただけの所にほかの見た目の項目が出ない） |
| 照合の時間 | 実データ：約38秒 → 約38秒。架空データ（旧版だけ・20ページ。各ページに図版の差し替え・ロゴの移動など）：29.5秒 → 33.4秒（見た目の比べ合わせの段階が 6.0秒 → 9.3秒。照合中のバーの見込みもこれに合わせた） |
